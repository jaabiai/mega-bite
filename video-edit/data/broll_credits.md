# B-roll credits

All stock clips come from **Mixkit** and were checked one by one: only clips marked
*Mixkit Stock Video Free License* ("free for commercial or personal use", no attribution required) were used.
Clips under the *Mixkit Restricted License* (personal use only) were deliberately skipped because the channel may be monetised.

Pexels was tried first, but it sits behind a Cloudflare bot-check and its API needs a key, so it was not used.
(If you add a Pexels API key later, clips can be swapped by changing the `BrollScene(...)` ids in `edl.py`.)
