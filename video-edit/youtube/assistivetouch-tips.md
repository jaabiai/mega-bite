Steps shown in the video:
* **Tip 1, screenshot without buttons:** Settings → search "AssistiveTouch" → turn it on → Customise Top Level Menu → +
  → tap the new slot → Device → Screenshot → Done (✓). Open the AssistiveTouch button → Screenshot.
* **Tip 2, restart without buttons:** Settings → AssistiveTouch → Customise Top Level Menu → + → new slot → System →
  Restart → Done (✓). Open the AssistiveTouch button → Restart.
