What the video shows (Equal AI app, iPhone and Android):
* **Set up:** open the app → it gives set-up instructions → allow the permissions it asks for (contacts, microphone)
  → copy the code and dial it (it only sets up call forwarding) → Verify → profile ready.
* **You tab:** AI Assistant on / off at any time.
* **Your Instructions:** ready-made presets (Busy, Everyday calls, Business) → Apply, or **Add new instruction** by
  voice note or by typing a message.
* **Your Call Preferences:** All calls / All calls except… / Only unknown numbers → Confirm.
* **Voice & Language:** pick up to 3 languages and a primary language; the assistant greets callers in the primary
  language and answers in the caller's language.
* **Assistant Voice:** Edit → pick a voice → Confirm.
* **Silent Mode:** mute promotional calls (loans, credit cards, jobs, real estate, others).
* Doubts → **Talk to Equal**; free plan + premium upgrade.
