### What the background is (requirement 4)

Everything behind the text is rendered frame-by-frame by `hinglish_landscape/tools/` from procedural code: lit volumetric-style cloud layers, HDR sun with god-rays,
layered mountain ridges with haze and rim light, city skylines with Jantar Mantar, India Gate, Red Fort / Jama Masjid and Parliament silhouettes, crowds with raised fists and
waving tricolours, cloth-simulated large flags, tricolour / saffron / red smoke, bokeh, diyas, birds, lightning; 29 shots cut on the song's 92.66 BPM bar grid with dissolve / flash /
smoke / whip transitions, ACES tone-mapping, bloom, vignette, film dither and a separate colour grade per mood (night → dawn → golden → red protest → storm → blue hour → vigil → glory).
The crowd, flag and Jantar-Mantar silhouettes reuse the drawing code of my own earlier portrait build (`tools/art.py`, imported read-only). No third-party footage, images or music were used, so there is nothing to attribute. Fonts are SIL OFL 1.1 (licences in `hinglish_landscape/assets/fonts/licenses/`).

**To meet requirement 4 properly:** allow `pexels.com`, `videos.pexels.com`, `images.pexels.com`, `api.pexels.com`, `pixabay.com`, `cdn.pixabay.com` in the environment's *Network access* settings and ask for the footage pass.
That needs new compositing code (stock clips as background layers, grading to match, licence log) — it has **not** been written or tested, so it is not claimed here.
